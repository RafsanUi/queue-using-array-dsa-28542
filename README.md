

# Queue Using Array

**Course:** Computer Data Structure and Algorithm  
**Course Code:** 28542  
**Language:** C Programming

## What is Queue?
Queue is a linear data structure that follows FIFO
(First In First Out) principle.

## Operations
1. Enqueue - Insert an element.
2. Dequeue - Remove an element.
3. Peek - Show the first element.
4. Is Empty - Check whether the queue is empty.
5. Length/Size - Count total elements.

## Capacity
Maximum size: 5

## How to Run

gcc queue.c -o queue
./
